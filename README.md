# Python: Zero to Warrior

The code for **Python: Zero to Warrior**, a free Python course for beginners from
[The Code Warrior](https://www.youtube.com/@askthecodewarrior) on YouTube.

Full course playlist: https://www.youtube.com/playlist?list=PLcsbg964FAwc

## How to use it
Each lesson has its own folder under `lessons/`:
- `solution.py` is the program from the video.
- `starter.py` is the "your turn" exercise, with TODOs for you to fill in.
- `README.md` sums up the lesson and gives you a few practice problems.

Watch the video first, then try `starter.py` on your own before you open `solution.py`.

To run a file, open its folder in VS Code, open a terminal, and type:
```
python3 solution.py      # Mac
python solution.py       # Windows
```
If you don't have Python and VS Code yet, lesson 01 shows you where to get them.
